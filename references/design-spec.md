# Signature Design Spec (do not deviate)

This is the exact visual system used for the delivered reports
(Assignment 6/7/9/10/11). The constants below are baked into `scripts/` —
only touch them if the user explicitly asks for a redesign.

## Page geometry (A4)

- Margins: left/right 2.2 cm, top 2.3 cm, bottom 2.0 cm
- Content width: 16.6 cm
- Page breaks: ONLY cover → TOC → body. Body flows continuously.
- Cover is its own page/frame; body starts on page 2 (TOC page).

## Palette

| Role | Hex |
|---|---|
| Navy accent (headings, table headers, border) | `#1F3A5F` |
| Ink (body text) | `#1A1A1A` |
| Gray (captions, header/footer, subtitles) | `#5B6472` |
| Rule gray (grid lines) | `#C9CFD8` |
| Zebra row | `#F2F5F9` |
| Summary row / shaded | `#E4EAF2` |
| Code panel | `#F5F6F8` |

## Cover page (the signature page — identical on every report, top to bottom)

1. Double navy frame: outer 1.6 pt rect at 1.1 cm inset, inner 0.5 pt rect at 1.32 cm inset (in DOCX: `w:pgBorders` double, sz 18, color 1F3A5F, offset from page, on the cover section only)
2. SIT logo banner (`assets/sit-logo.png`) — centered, 8.5 cm wide (≈1.16 cm tall), first element inside the frame, ~0.55 cm below the inner border, ~0.5 cm above the department line (in DOCX: inline picture in a centered paragraph, same width)
3. Department line — Calibri bold 10.5, gray, centered, ALL CAPS
4. Short navy rule — 38% width, 1.1 pt
5. Course title — Calibri bold 21, ink, centered
6. AY line — "AY 2026-27 | Batch 2025-2029", Calibri 11 gray centered
7. (2 cm gap) Badge — "EXPERIMENT 6" / "ASSIGNMENT 10", Calibri bold 12.5, navy, centered
8. Main title — Calibri bold 28, ink, centered (wraps to 2 lines when long)
9. Subtitle — Calibri italic 12, gray, centered
10. (2 cm gap) Fields table — 2 cols (4.6 / 8.6 cm), rows: Name, PRN / Roll No., Assignment, Course, Date. Labels Calibri bold 10.5 navy; values Cambria 11 ink. Navy 1 pt line above first row and below last row; 0.4 pt gray rules between rows; generous 7 pt cell padding
11. "Academic Year 2026-27" — Calibri 9.5 gray centered

The logo is part of the fixed cover — always the bundled `assets/sit-logo.png`
(never a different or re-downloaded logo), always 8.5 cm wide, always the top
slot above the department line. Override/remove only via spec `meta.logo`
(path, or `null` for no logo). No page number, no header on the cover.

## TOC page

- Title "Table of Contents" Calibri bold 16 navy + full-width navy rule
- Level 1 entries: sans bold 10.5; level 2: serif 10, indented 18 pt
- Dot leaders to right-aligned page numbers (PDF: generated by multiBuild;
  DOCX: real TOC field, user updates in Word)

## Body typography

- H1: Calibri bold 14.5 navy, space before 18 / after 7, keep-with-next
- H2: Calibri bold 11.5 ink, before 13 / after 5, keep-with-next
- Body: Cambria (serif) 10.5 / leading 16, justified
- Bullets and numbered lists: LEFT-aligned (never justified), tight spacing
- Captions: Calibri italic 9 gray, centered, "Figure N: ..." numbered per doc
- Formulas: centered, serif math font, sub/super via tags

## Running header/footer (body pages only)

- Header: left "course | AY 2026-27", right short report title, Calibri 8.5 gray, thin gray rule under
- Footer: thin gray rule above, centered "Page N", Calibri 8.5 gray

## Tables

- Header row: navy background, white Calibri bold 9, centered
- Cells: serif 9.5; thin 0.4 pt gray grid; zebra striping [white, #F2F5F9]
- Summary rows (Accuracy / avg / total): shaded #E4EAF2, bold
- Row-label column may be bold; vertical centering; 5 pt cell padding

## Code blocks

- Consolas/mono 7.9 pt, leading 10.6, on #F5F6F8 panel
- Navy 2.2 pt left bar; splits across pages line-by-line (never overflows)

## Character safety

- Superscripts/subscripts via `<super>`/`<sub>` tags only — never unicode ² ³ ₁
- Greek/math letters (β η μ Σ ξ ε √ ×) only in Math-font contexts (formula
  blocks, math table cells, `<font face="Math">` spans)
- Em dashes, straight quotes; no emoji; no "End of report" markers
